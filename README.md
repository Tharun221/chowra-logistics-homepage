# CHOWRA LOGISTICS AND COURIERS LIMITED

## Technical Round Assignment

A modern, responsive sample homepage developed for **CHOWRA LOGISTICS AND COURIERS LIMITED** as part of the technical evaluation for SAC Info Tech Solutions.

## Project Overview

The project demonstrates a professional logistics and courier website experience focused on shipment tracking, courier services, express delivery, e-commerce logistics, freight and cargo services, network coverage, quotation estimation, and corporate logistics solutions.

The website has been designed with a responsive, mobile-first approach and includes interactive components using vanilla JavaScript.

## Key Features

* Responsive desktop, tablet and mobile layout
* Professional logistics-focused homepage
* Responsive navigation with services mega-menu
* Mobile navigation experience
* Shipment tracking demonstration
* Five-step shipment delivery timeline
* Indicative quote calculator
* Document, parcel and cargo shipment options
* Volumetric-weight calculation
* Delivery-speed estimation
* Animated trust/statistics counters
* Logistics service cards
* Industry solutions section
* Illustrative India network coverage map
* Technology/logistics dashboard
* Customer testimonial carousel
* Responsive footer with accordion sections
* Smooth interactions and UI animations

## Functional Demonstrations

### Shipment Tracking

Users can enter a sample tracking number and view:

* Shipment information
* Current shipment status
* Origin and destination
* Delivery progress
* Five-step shipment timeline

### Quote Calculator

The quote calculator demonstrates indicative shipment pricing based on:

* Shipment type
* Weight
* Volumetric weight
* Delivery speed
* Shipment category

The displayed values are demonstration calculations only.
